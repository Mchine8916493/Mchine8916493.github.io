1. 电机控制概述

电机控制是对电机电压、电流、转速、转矩、位置等物理量进行精确调控的技术。核心是控制电磁转矩，最终实现对转速/位置的控制。

机械运动方程 J·dω/dt = Te - TL 表明：控制转速的本质是精确控制电磁转矩 Te 与负载转矩 TL 之差。

工业自动化 伺服电机、变频器、机器人 高精度、高动态响应

消费电子 电动工具、吸尘器、风扇 小型化、低功耗
新兴领域 人形机器人、eVTOL、电动船舶、风电变桨 高功率密度、智能控制

2.4 PMSM 的 dq 坐标系数学模型

在旋转 dq 坐标系下，PMSM 的电压方程和转矩方程：

  • SPM（Ld = Lq）：只有励磁转矩，Id = 0 控制即可获得最大转矩/最高效率
  • IPM（Ld < Lq）：励磁转矩 + 磁阻转矩，通过 MTPA 找到最佳 Id/Iq 分配

3. 控制策略总览

FOC 的优点：相比 VVVF，带负载能力强、不易失步、动态响应好；相比方波控制，低速性能好、转矩脉动小、噪声低。

4. FOC 磁场定向控制详解

4.1 核心思想

FOC 的基本思想：将三相定子电流解耦为”控制磁场的电流分量（Id）”和”控制转矩的电流分量（Iq）”，独立控制二者。经坐标变换后，交流电机控制变得像直流电机一样简单。

FOC 的物理直觉：

  • 三相绕组通电产生旋转磁场（难以直接控制）
  • 通过 Clarke + Park 变换，把交流量变成旋转坐标系下的直流量
  • 在 dq 旋转坐标系里控制电流 → 等价于给两个”电磁铁”通直流电，磁场稳定，转矩计算简单
  • 只有 q 轴电流（Iq，转矩电流）产生转矩；d 轴电流（Id，励磁电流）调节磁链、不产生转矩

4.4 SVPWM 空间矢量调制

  • 理论基础：平均值等效原理——在一个开关周期内，用基本电压矢量的组合使平均值等于给定电压矢量
  • 三相全桥逆变器 6 个开关管 → 8 种开关状态：6 个非零矢量 + 2 个零矢量
  • 六边形矢量空间分为 6 个扇区，每扇区 60°
  • 控制步骤：判断扇区 → 计算相邻矢量作用时间 → 安排开关序列（中心对齐/边缘对齐，最小化开关损耗）
  • 与普通正弦 PWM 相比，SVPWM 直流电压利用率更高（可提升约 15%）

4.5 FOC 电流控制策略

控制策略 适用电机 说明
Id = 0 控制 SPM（表贴式） 最简单，Iq 即全部转矩电流，单位电流转矩最大
MTPA（最大转矩电流比） IPM（内置式） 找到 Id/Iq 最优分配，相同电流输出最大转矩
弱磁控制（FW） 所有，超额定转速 给 d 轴施加负电流削弱气隙磁链，突破额定转速上限
最大效率控制 高效应用 兼顾铜耗与铁耗

弱磁控制原理：逆变器输出电压受限，BEMF 与转速成正比，当电压饱和时通过降低等效磁链（施加负 Id）来提高转速上限，代价是转矩下降。

4.6 典型 FOC 控制框图（三闭环）

  • 快环（电流环）：16-32kHz，负责转矩/磁链解耦控制
  • 慢环（速度环）：通常为电流环的 1/10，输出 Iqref
  • 可选位置环（伺服应用）：输出速度指令

5. 无位置传感器控制

5.1 为什么需要无感控制

  • 位置传感器（编码器、旋转变压器、霍尔）增加成本、体积和维护难度
  • 风机、水泵、压缩机等应用对成本敏感，无感方案需求旺盛
  • 目标：通过电流/电压估算转子位置和转速

5.2 主流无感算法对比

算法 原理 优点 缺点
滑模观测器（SMO） 基于反电势的滑模面设计，含转子位置信息 对参数变化和扰动自适应强，实现简单，对 MCU 资源要求低 固有抖振，需饱和函数+边界层抑制
反电势观测器 从电压电流方程观测 BEMF 中高速效果好 低速/零速时 BEMF 太小失效
磁链观测器 观测定子磁链 实现简单 需积分，存在漂移
卡尔曼滤波器（EKF） 最优状态估计 精度高、抗噪强 计算量大，需矩阵运算
模型参考自适应（MRAS） 参考模型+可调模型误差校正 鲁棒性好 参数依赖、收敛速度
Luenberger 观测器 状态观测器 理论成熟 依赖精确电机模型
PLL 锁相环法 对反电势 dq 分量用 PLL 跟踪角度 直接得到角度和转速，不需角度补偿 引入额外 PI，需要调试

5.3 滑模观测器（SMO）实现要点

  • 用 RL 负载模型近似 PMSM，反电势 es 包含转子位置信息
  • 传统切换函数（开关函数）产生抖振 → 用饱和函数替代，选择合理边界层厚度削弱抖振
  • 提取转子角度两种方式：
    • 反正切法：收敛快、简单，但角度不平滑、有相位滞后，需补偿，转速由角度微分获得有波动
    • 锁相环法（PLL）：不需角度补偿，直接获得转速，但引入 PI 调节器（推荐）

5.5 有传感器方案（霍尔/编码器）

  • 霍尔传感器：3 个霍尔互差 60°/120° 电角度，将电周期分为 6 个扇区（每 60°）
  • 转子预定位后，通过霍尔信号边界插补计算角速度，在 PWM 中断里插补转子角度
  • 适用于要求不高但需要可靠低速性能的应用（如电动自行车、风扇）

6. 硬件系统设计

6.1 电机驱动系统架构

核心组成部分：

  1. MCU/DSP：运行 FOC 算法，ADC 采样，PWM 生成
  2. 前置驱动器（Pre-driver/栅极驱动器）：放大 MCU 的 PWM 信号驱动功率管
  3. 功率级：6 个 N-MOSFET / IGBT / SiC MOSFET / GaN 组成三相全桥逆变器
  4. 模拟反馈：母线电压、相电流采样
  5. 位置检测（可选）：编码器、旋转变压器、霍尔

6.2 功率器件选型

器件 电压等级 开关频率 特点 应用
MOSFET（Si） <250V 高 导通损耗与电压相关 家电、电动工具、低压伺服
IGBT 600-1200V 中（2-20kHz） 饱和压降特性，大电流 工业变频、中高压电机
SiC MOSFET 650-1700V 高（可达 60kHz+） 宽禁带 3.26eV，高温高效 800V 新能源汽车牵引逆变器
GaN HEMT 650V 极高 开关速度 <5ns，体积小 小型伺服、数据中心

SiC 的优势（对比 Si IGBT）：

  • 禁带宽度 3.26eV vs 1.12eV → 更高耐压、更高工作温度（150°C+）
  • 开关损耗大幅降低，支持更高开关频率 → 减小磁件和散热器尺寸
  • 案例（TI TIDM-02014）：300kW SiC 牵引逆变器，功率密度 32.25kW/L，是 Si 方案 2 倍多

6.3 栅极驱动设计要点（重点！）

参考：Wolfspeed《SiC MOSFET 栅极驱动》、onsemi《SiC 栅极驱动优化》

SiC 栅极驱动要求：

  • 驱动供电：开通正压 + 关断负压（推荐 +15V / -4V，容差 ±5%）
  • 共模瞬态抗扰度 CMTI > 100 kV/µs（SiC 硬开关 dV/dt 可达 150V/ns）
  • 最大工作绝缘电压可达 1700V
  • 驱动能力可达 10A（大功率 SiC 模块）
  • 传输延迟 <10ns，通道匹配 <10ns
  • 主动米勒钳位：防高 dV/dt 串扰导致误导通
  • 快速短路保护（去饱和检测 DESAT）：检测时间 250-500ns，软停机 400-1500ns，总短路时间 <1-1.5µs

栅极驱动电源功率估算：

为什么需要负压关断：图腾柱/桥式应用中高 dV/dt 和 di/dt 会产生串扰，在栅极产生电压尖峰，负压关断（-4V）防止误导通，同时保证最大允许负压 -8V 有足够余量。

并联 MOSFET 要点：每个管子单独接栅极电阻（防止振荡），Kelvin source 加 1Ω 电阻，对称布局保证均流。

6.4 电流检测方案

方案 原理 优点 缺点 适用
低侧分流电阻 采样电阻 + 运放放大 低成本、精度高 需在 PWM 特定时刻采样 中小功率（家电、工具）
三电阻采样 三只分流电阻重构三相电流 每相独立 占空比小时采样窗口不足 伺服、工业驱动
单电阻采样 一个分流电阻 + 重构 成本最低 算法复杂，低调制区失真 低成本方案
霍尔电流传感器 磁场检测 隔离、无插入损耗 成本高、带宽受限 中大功率
Δ-Σ 调制器 隔离式电流检测 高精度、隔离 需外部滤波器 汽车/高压应用

9.2 三大技术趋势

趋势一：SiC/GaN 全面渗透

  • SiC MOSFET 从”实验室明星”变为”量产主力”，800V 高压平台标配

  • 结合过调制、载频动态调整、DPWM 发波等算法，系统效率持续攀升
  • 挑战：SiC 成本仍高于 Si，通过大晶圆利用率和封装工艺创新降本

趋势二：多合一集成

  • “电机+电控+减速器+电源”深度集成成为标配
  • 通信升级：高速串行总线替代 CAN，与域控制器实时交互扭矩指令
  • 竞争分水岭：从”零部件供应商”升级为”系统解决方案提供商”

趋势三：AI 深度融合，软件定义硬件

  • 基于深度学习的自适应控制、故障预测、参数自整定成为标配
  • 数字孪生技术加速开发周期，虚拟仿真减少物理样机

  • 商业模式：硬件订阅/性能即服务渗透率 2025 年达 14%
