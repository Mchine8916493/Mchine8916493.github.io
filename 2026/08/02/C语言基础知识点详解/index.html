C语言基础知识点详解

C 语言是嵌入式、操作系统、驱动开发与高性能计算的基石。本文面向初学者，系统梳理 C 语言基础知识点，从”程序长什么样”到”怎么组织代码”，为后续的进阶学习（指针深入、内存管理、编译链接）打下地基。建议配合《C语言进阶知识点详解》一起阅读。

二、基本数据类型

2.1 整数类型

类型 典型大小 取值范围（典型 32 位平台）
char 1 字节 -128 ~ 127
unsigned char 1 字节 0 ~ 255
short 2 字节 -32768 ~ 32767
int 4 字节 -2147483648 ~ 2147483647
unsigned int 4 字节 0 ~ 4294967295
long 4 或 8 字节 平台相关
long long 8 字节 -2^63 ~ 2^63-1

记忆：sizeof(int) 在大多数平台是 4 字节，但 C 标准只保证 int ≥ 16 位。想要确定宽度用 <stdint.h> 的 int32_t、uint8_t 等。

2.2 浮点类型

字面量加 f/L 后缀指定类型；默认小数是 double。浮点不能直接比较相等（精度问题）。

三、变量与常量

3.1 变量声明与初始化

未初始化的局部变量是不确定值，直接使用属于未定义行为，是初学者的头号陷阱。

3.2 常量

3.3 命名规则

  • 只能由字母、数字、下划线组成，且不能以数字开头
  • 不能与关键字（if、int、return 等）重名
  • 大小写敏感：Sum、sum、SUM 是三个不同变量
  • 常见风格：snake_case（变量/函数）、SCREAMING_CASE（宏）

四、运算符

4.1 算术运算符

  • /：整数相除截断小数（7 / 2 == 3），浮点相除才保留小数（7.0 / 2 == 3.5）
  • %：取余，仅用于整数（7 % 2 == 1）
  • 除零是运行时错误

4.2 赋值与复合赋值

4.3 自增自减

一条语句里不要多次修改同一个变量（i = i++ + i 是未定义行为）。

4.4 关系与逻辑运算符

  • 短路求值：a && b 若 a 为假则不计算 b；a || b 若 a 为真则不计算 b
  • !0 == 1，!5 == 0（C 中任何非 0 值都是”真”）
  • 常见错误：if (a = 5) 是赋值不是比较！应为 if (a == 5)

5.1 if / else if / else

  • if 只控制紧随其后的一条语句；要控制多句必须加大括号 {}

十三、常见错误与调试

13.1 初学者高频错误

错误 正确写法 原因
if (a = 5) if (a == 5) = 是赋值，== 才是比较
scanf("%d", n) scanf("%d", &n) scanf 需要地址
int a[5]; a[5]=1; 下标 0~4 越界是未定义行为
忘记初始化 int sum = 0; 垃圾值参与运算
7 / 2 == 3.5 7 / 2 == 3 整数除法截断
字符串数组不给 \0 留位 char s[6]="hello" 少 1 个字节越界

13.2 调试技巧

  • 使用 GDB 断点单步调试

十四、编码风格建议

总结

C 语言基础知识点构成一张完整的入门地图：

程序结构 → 数据类型 → 变量常量 → 运算符 → 流程控制 → 数组 → 函数 → 指针入门 → 作用域 → 预处理 → 输入输出

掌握这些内容后，你就可以写出完整的小程序（猜数字、排序、简易计算器）。下一站就是进阶篇：指针深入、内存管理、结构体、位操作、编译链接与未定义行为。

一句话记住：C 语言基础 = 用”变量存数据、运算符算数据、流程控流程、函数组逻辑”，把这三件事练到条件反射，就算入门了。
