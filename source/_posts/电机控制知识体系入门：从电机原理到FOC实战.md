## 1. 电机控制概述

电机控制是对电机**电压、电流、转速、转矩、位置**等物理量进行精确调控的技术。核心是控制电磁转矩，最终实现对转速/位置的控制。

机械运动方程 `J·dω/dt = Te - TL` 表明：**控制转速的本质是精确控制电磁转矩 Te 与负载转矩 TL 之差**。

### 1.1 应用领域

| 领域 | 典型应用 | 特点 |
|---|---|---|
| 新能源汽车 | 主驱电机（牵引逆变器） | 高功率（100-300kW）、800V 高压、功能安全 |
| 工业自动化 | 伺服电机、变频器、机器人 | 高精度、高动态响应 |
| 家电 | 变频空调/冰箱/洗衣机 | 低成本、低噪声、高效 |
| 消费电子 | 电动工具、吸尘器、风扇 | 小型化、低功耗 |
| 新兴领域 | 人形机器人、eVTOL、电动船舶、风电变桨 | 高功率密度、智能控制 |

## 2. 电机类型与数学模型

### 2.1 常见电机类型

```
直流电机（有刷）
    ├── 优点：控制简单（电压即可调速）
    └── 缺点：电刷磨损、需维护

交流电机
    ├── 异步电机（ACIM/感应电机）
    │       ├── 鼠笼式转子，结构简单，成本低
    │       └── 需要励磁电流产生转子磁通（Idref ≠ 0）
    ├── 永磁同步电机（PMSM）
    │       ├── 转子为永磁体，无励磁损耗，效率高
    │       ├── 表面贴装型 SPM：Ld = Lq，只产生励磁转矩
    │       └── 内置式 IPM：Ld ≠ Lq，励磁转矩 + 磁阻转矩
    ├── 无刷直流电机（BLDC）
    │       ├── 梯形波反电势
    │       └── 可用方波（六步）控制，也可用 FOC
    └── 开关磁阻电机（SRM）
            └── 双凸极结构，鲁棒性极强但噪声大
```

### 2.2 PMSM 与 BLDC 的区别

| 特性 | BLDC | PMSM |
|---|---|---|
| 反电动势波形 | 梯形波 | 正弦波 |
| 转矩脉动 | 大 | 小 |
| 运行噪声 | 大 | 小 |
| 控制方式 | 方波控制为主 | FOC 矢量控制为主 |
| 低速性能 | 差 | 好 |

> 重要认知：**BLDC 也可以用矢量控制，PMSM 也可以用方波控制**。二者硬件结构几乎相同，区别在于反电势波形和控制策略选择。

### 2.3 方波控制 vs 矢量控制

| 控制方法 | 方波控制（六步换相） | 矢量控制（FOC） |
|---|---|---|
| 转矩脉动 | 大 | 小 |
| 算法复杂度 | 简单 | 复杂 |
| 运行噪声 | 大 | 小 |
| 低速性能 | 差 | 好 |
| 导通相数 | 同一时间两相导通 | 三相同时导通 |
| 位置检测 | 每 60° 电角度换相 | 连续位置检测 |
| 开关损耗 | 小 | 大 |
| 高速性能 | 高 | 受限于 PWM 频率 |

### 2.4 PMSM 的 dq 坐标系数学模型

在旋转 dq 坐标系下，PMSM 的电压方程和转矩方程：

```
电压方程：
  Vd = Rs·Id + Ld·dId/dt - ωe·Lq·Iq
  Vq = Rs·Iq + Lq·dIq/dt + ωe·(Ld·Id + Ψf)

电磁转矩方程：
  Te = 1.5·P·[Ψf·Iq + (Ld - Lq)·Id·Iq]
       └──────────┘    └────────────┘
       励磁转矩            磁阻转矩
```

- **SPM（Ld = Lq）**：只有励磁转矩，**Id = 0 控制**即可获得最大转矩/最高效率
- **IPM（Ld < Lq）**：励磁转矩 + 磁阻转矩，通过 **MTPA** 找到最佳 Id/Iq 分配

## 3. 控制策略总览

```
电机控制策略
├── 标量控制（VVVF 变频调速）
│       └── 只控电压幅值和频率，动态响应差，易失步
├── 矢量控制（FOC，磁场定向控制）★ 主流
│       ├── 转子磁场定向
│       └── 定子磁场定向（用于异步机）
├── 直接转矩控制（DTC）
│       ├── 直接控制转矩和磁链，响应快
│       └── 转矩脉动大，需查表（开关表）
└── 现代先进控制
        ├── 模型预测控制（MPC）
        ├── 自适应控制
        ├── 滑模控制（SMC）
        └── AI/深度学习控制（2026 趋势）
```

**FOC 的优点**：相比 VVVF，带负载能力强、不易失步、动态响应好；相比方波控制，低速性能好、转矩脉动小、噪声低。

## 4. FOC 磁场定向控制详解

### 4.1 核心思想

FOC 的基本思想：**将三相定子电流解耦为"控制磁场的电流分量（Id）"和"控制转矩的电流分量（Iq）"，独立控制二者**。经坐标变换后，交流电机控制变得像直流电机一样简单。

FOC 的物理直觉：
- 三相绕组通电产生旋转磁场（难以直接控制）
- 通过 Clarke + Park 变换，把交流量变成**旋转坐标系下的直流量**
- 在 dq 旋转坐标系里控制电流 → 等价于给两个"电磁铁"通直流电，磁场稳定，转矩计算简单
- 只有 **q 轴电流（Iq，转矩电流）产生转矩**；d 轴电流（Id，励磁电流）调节磁链、不产生转矩

### 4.2 FOC 执行步骤

```
1. 采样三相电流（通常只采两相 ia、ib，第三相 ic = -(ia+ib)）
2. Clarke 变换：三相静止 → 两相静止（αβ）
3. 获取转子位置角 θ（传感器或观测器估算）
4. Park 变换：两相静止 αβ → 两相旋转 dq
5. 电流环 PI 控制：Id → Idref，Iq → Iqref（独立控制）
6. 反 Park 变换：dq → αβ（得到电压指令）
7. SVPWM 空间矢量调制：生成三相 PWM 驱动逆变器
```

### 4.3 坐标变换（核心数学）

**Clarke 变换**（三相静止 → 两相静止）：

```
[ Iα ]   [ 1       -1/2    -1/2 ] [ Ia ]
[    ] = [                        ] [    ]
[ Iβ ]   [ 0       √3/2   -√3/2 ] [ Ib ]
                                  [ Ic ]
```

**Park 变换**（两相静止 → 两相旋转，需转子角度 θ）：

```
[ Id ]   [ cosθ   sinθ ] [ Iα ]
[    ] = [              ] [    ]
[ Iq ]   [ -sinθ  cosθ ] [ Iβ ]
```

**意义**：变换后 Id、Iq 是直流量 → 可以用 PI 控制器实现无静差控制；并且"从旋转坐标系看，磁动势、电压、电流全是直流量"，控制被极大简化。

### 4.4 SVPWM 空间矢量调制

- 理论基础：**平均值等效原理**——在一个开关周期内，用基本电压矢量的组合使平均值等于给定电压矢量
- 三相全桥逆变器 6 个开关管 → 8 种开关状态：**6 个非零矢量 + 2 个零矢量**
- 六边形矢量空间分为 6 个扇区，每扇区 60°
- 控制步骤：判断扇区 → 计算相邻矢量作用时间 → 安排开关序列（中心对齐/边缘对齐，最小化开关损耗）
- 与普通正弦 PWM 相比，SVPWM 直流电压利用率更高（可提升约 15%）

### 4.5 FOC 电流控制策略

| 控制策略 | 适用电机 | 说明 |
|---|---|---|
| **Id = 0 控制** | SPM（表贴式） | 最简单，Iq 即全部转矩电流，单位电流转矩最大 |
| **MTPA（最大转矩电流比）** | IPM（内置式） | 找到 Id/Iq 最优分配，相同电流输出最大转矩 |
| **弱磁控制（FW）** | 所有，超额定转速 | 给 d 轴施加负电流削弱气隙磁链，突破额定转速上限 |
| **最大效率控制** | 高效应用 | 兼顾铜耗与铁耗 |

**弱磁控制原理**：逆变器输出电压受限，BEMF 与转速成正比，当电压饱和时通过降低等效磁链（施加负 Id）来提高转速上限，代价是转矩下降。

### 4.6 典型 FOC 控制框图（三闭环）

```
速度指令 nref ──→ [速度环PI] ──→ Iqref ──→ [电流环PI] ──→ Vqref ──→ 反Park ──→ SVPWM ──→ 逆变器 ──→ 电机
                    ↑                 Idref(=0/MTPA) ─→ [电流环PI] ──→ Vdref ──↑           │
                    │                                                                     │
                转速反馈 ←── 位置微分 ── 位置/角度（编码器/霍尔/观测器） ←── 电流采样 ←── 电流传感器
```

- **快环**（电流环）：16-32kHz，负责转矩/磁链解耦控制
- **慢环**（速度环）：通常为电流环的 1/10，输出 Iqref
- 可选**位置环**（伺服应用）：输出速度指令

## 5. 无位置传感器控制

### 5.1 为什么需要无感控制

- 位置传感器（编码器、旋转变压器、霍尔）增加**成本、体积和维护难度**
- 风机、水泵、压缩机等应用对成本敏感，无感方案需求旺盛
- 目标：通过电流/电压估算转子位置和转速

### 5.2 主流无感算法对比

| 算法 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **滑模观测器（SMO）** | 基于反电势的滑模面设计，含转子位置信息 | 对参数变化和扰动自适应强，实现简单，对 MCU 资源要求低 | 固有抖振，需饱和函数+边界层抑制 |
| **反电势观测器** | 从电压电流方程观测 BEMF | 中高速效果好 | 低速/零速时 BEMF 太小失效 |
| **磁链观测器** | 观测定子磁链 | 实现简单 | 需积分，存在漂移 |
| **卡尔曼滤波器（EKF）** | 最优状态估计 | 精度高、抗噪强 | 计算量大，需矩阵运算 |
| **模型参考自适应（MRAS）** | 参考模型+可调模型误差校正 | 鲁棒性好 | 参数依赖、收敛速度 |
| **Luenberger 观测器** | 状态观测器 | 理论成熟 | 依赖精确电机模型 |
| **PLL 锁相环法** | 对反电势 dq 分量用 PLL 跟踪角度 | 直接得到角度和转速，不需角度补偿 | 引入额外 PI，需要调试 |

### 5.3 滑模观测器（SMO）实现要点

- 用 RL 负载模型近似 PMSM，反电势 `es` 包含转子位置信息
- 传统切换函数（开关函数）产生**抖振** → 用**饱和函数**替代，选择合理边界层厚度削弱抖振
- 提取转子角度两种方式：
  - **反正切法**：收敛快、简单，但角度不平滑、有相位滞后，需补偿，转速由角度微分获得有波动
  - **锁相环法（PLL）**：不需角度补偿，直接获得转速，但引入 PI 调节器（推荐）

### 5.4 无感启动策略（三阶段）

无感 FOC 在零速无法观测反电势，必须采用特殊启动策略：

```
阶段1：转子预定位（对齐）
  施加固定电压矢量，让转子对齐到已知位置（如 U 相轴线）
  → 保证零速下可施加全部启动转矩

阶段2：开环启动
  位置未知状态下，用 I/f 或 V/f 开环拖动，转速逐渐上升
  直到观测器能提供可靠的速度/位置估计

阶段3：切换闭环
  当观测器估计误差足够小时，从开环无缝切换到闭环 FOC
  → 切换平顺性是无感启动的关键难点
```

### 5.5 有传感器方案（霍尔/编码器）

- **霍尔传感器**：3 个霍尔互差 60°/120° 电角度，将电周期分为 6 个扇区（每 60°）
- 转子预定位后，通过霍尔信号边界插补计算角速度，在 PWM 中断里插补转子角度
- 适用于要求不高但需要可靠低速性能的应用（如电动自行车、风扇）

## 6. 硬件系统设计

### 6.1 电机驱动系统架构

```
┌────────────────────────────────────────────────────────┐
│                   电机驱动系统                           │
│                                                        │
│  ┌─────────┐   ┌───────────┐   ┌──────────────────┐   │
│  │   MCU   │──▶│  栅极驱动  │──▶│ 功率级（三相全桥） │   │
│  │ (控制)  │   │ (Gate Drv) │   │  MOSFET/IGBT/SiC │──▶│──▶ 电机
│  └─────────┘   └───────────┘   └──────────────────┘   │
│      │                 │               │              │
│      │            ┌────┴─────┐   ┌─────┴──────┐       │
│      │            │ 辅助电源  │   │  电流/电压   │       │
│      │            │ 隔离DC/DC│   │   采样反馈   │       │
│      └────────────┴──────────┴───┴────────────┘       │
│            通信（CAN/UART/SPI）+ 位置传感器（可选）      │
└────────────────────────────────────────────────────────┘
```

**核心组成部分：**
1. **MCU/DSP**：运行 FOC 算法，ADC 采样，PWM 生成
2. **前置驱动器（Pre-driver/栅极驱动器）**：放大 MCU 的 PWM 信号驱动功率管
3. **功率级**：6 个 N-MOSFET / IGBT / SiC MOSFET / GaN 组成三相全桥逆变器
4. **模拟反馈**：母线电压、相电流采样
5. **位置检测**（可选）：编码器、旋转变压器、霍尔

### 6.2 功率器件选型

| 器件 | 电压等级 | 开关频率 | 特点 | 应用 |
|---|---|---|---|---|
| **MOSFET（Si）** | <250V | 高 | 导通损耗与电压相关 | 家电、电动工具、低压伺服 |
| **IGBT** | 600-1200V | 中（2-20kHz） | 饱和压降特性，大电流 | 工业变频、中高压电机 |
| **SiC MOSFET** | 650-1700V | 高（可达 60kHz+） | 宽禁带 3.26eV，高温高效 | 800V 新能源汽车牵引逆变器 |
| **GaN HEMT** | 650V | 极高 | 开关速度 <5ns，体积小 | 小型伺服、数据中心 |

**SiC 的优势**（对比 Si IGBT）：
- 禁带宽度 3.26eV vs 1.12eV → 更高耐压、更高工作温度（150°C+）
- 开关损耗大幅降低，支持更高开关频率 → 减小磁件和散热器尺寸
- 案例（TI TIDM-02014）：300kW SiC 牵引逆变器，功率密度 32.25kW/L，是 Si 方案 2 倍多

### 6.3 栅极驱动设计要点（重点！）

参考：Wolfspeed《SiC MOSFET 栅极驱动》、onsemi《SiC 栅极驱动优化》

**SiC 栅极驱动要求：**
- 驱动供电：**开通正压 + 关断负压**（推荐 +15V / -4V，容差 ±5%）
- 共模瞬态抗扰度 **CMTI > 100 kV/µs**（SiC 硬开关 dV/dt 可达 150V/ns）
- 最大工作绝缘电压可达 1700V
- 驱动能力可达 10A（大功率 SiC 模块）
- 传输延迟 <10ns，通道匹配 <10ns
- **主动米勒钳位**：防高 dV/dt 串扰导致误导通
- **快速短路保护（去饱和检测 DESAT）**：检测时间 250-500ns，软停机 400-1500ns，总短路时间 <1-1.5µs

**栅极驱动电源功率估算：**
```
P = Freq × Qg × Vgs(total) × N
（Freq 开关频率，Qg 总栅极电荷，Vgs 栅压摆幅，N 并联数量）
```

**为什么需要负压关断**：图腾柱/桥式应用中高 dV/dt 和 di/dt 会产生串扰，在栅极产生电压尖峰，负压关断（-4V）防止误导通，同时保证最大允许负压 -8V 有足够余量。

**并联 MOSFET 要点**：每个管子单独接栅极电阻（防止振荡），Kelvin source 加 1Ω 电阻，对称布局保证均流。

### 6.4 电流检测方案

| 方案 | 原理 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **低侧分流电阻** | 采样电阻 + 运放放大 | 低成本、精度高 | 需在 PWM 特定时刻采样 | 中小功率（家电、工具） |
| **三电阻采样** | 三只分流电阻重构三相电流 | 每相独立 | 占空比小时采样窗口不足 | 伺服、工业驱动 |
| **单电阻采样** | 一个分流电阻 + 重构 | 成本最低 | 算法复杂，低调制区失真 | 低成本方案 |
| **霍尔电流传感器** | 磁场检测 | 隔离、无插入损耗 | 成本高、带宽受限 | 中大功率 |
| **Δ-Σ 调制器** | 隔离式电流检测 | 高精度、隔离 | 需外部滤波器 | 汽车/高压应用 |

## 8. 软件实现与调试

### 8.1 控制频率选择

| 环路 | 典型频率 | 说明 |
|---|---|---|
| 电流环（FOC 快环） | 16-32kHz | PWM 中断内执行全部坐标变换+PI |
| 速度环 | 1-5kHz | 电流环的 1/10 左右 |
| 位置环 | 0.5-2kHz | 伺服应用 |

### 8.2 中断架构（参考 NXP AN13184）

```
PWMA 比较中断（16kHz，最低优先级）
  └── PMSM FOC 快环 + 慢环

ADC 采样完成中断（32kHz，最高优先级）
  └── PFC 电流环（交错 PFC 场景）

PIT 定时中断（10kHz，中优先级）
  └── 峰值检测、母线电压控制状态机
```

### 8.3 PI 参数整定

- 电流环：基于电机电气常数（Rs、Ls），用极点配置或工程整定（如 Ziegler-Nichols）
- 速度环：基于机械时间常数，带宽通常为电流环 1/10
- 现代工具：厂商 IDE 提供自动整定（如 ST Motor Profiler、TI Motor Control SDK）

### 8.4 调试工具

- **FreeMASTER**（NXP）：实时变量可视化、远程控制
- **Motor Profiler / GUI**（ST、MPS）：自动识别电机参数
- **J-Scope / RTT**（Segger）：高速流传输调试
- **MathWorks**：Simulink 模型 + 自动代码生成（TIDM-02012 参考）

### 8.5 常见问题排查

| 现象 | 可能原因 |
|---|---|
| 电机不转/抖动 | 相序接反、霍尔/编码器时序错误、开环参数不当 |
| 过流 | 死区时间不足、电流环 PI 超调、短路保护误触发 |
| 噪声大/啸叫 | 载波频率进入可听频段、PWM 分辨率不足、死区补偿不当 |
| 高速失步 | 弱磁策略不当、电压饱和未补偿 |
| 无感启动失败 | 切换闭环时机过早、观测器收敛慢 |

## 9. 行业趋势与市场（2026）

### 9.1 市场数据

- 2025 年中国电机控制器市场规模约 **310 亿美元**，全球最大市场
- 2025 年全球车用电机控制器出货量 **1.9 亿台**，占整体市场 52% 以上
- 中国智能电机控制市场规模 2025 年约 **487 亿元**，预计 2030 年达 1,120 亿元（CAGR 18.3%）
- 2025 年宽禁带半导体（SiC/GaN）电机控制器出货突破 2500 万套，同比增长 82%
- 中国是全球最大汽车电机控制器生产国，本土厂商在中低端份额持续提升

### 9.2 三大技术趋势

**趋势一：SiC/GaN 全面渗透**
- SiC MOSFET 从"实验室明星"变为"量产主力"，800V 高压平台标配
- 开关频率提升、损耗显著降低、支持更高温度 → 散热系统体积减小
- 结合**过调制、载频动态调整、DPWM 发波**等算法，系统效率持续攀升
- 挑战：SiC 成本仍高于 Si，通过大晶圆利用率和封装工艺创新降本

**趋势二：多合一集成**
- "电机+电控+减速器+电源"深度集成成为标配
- 通信升级：高速串行总线替代 CAN，与域控制器实时交互扭矩指令
- 竞争分水岭：从"零部件供应商"升级为"系统解决方案提供商"

**趋势三：AI 深度融合，软件定义硬件**
- 基于深度学习的**自适应控制、故障预测、参数自整定**成为标配
- **数字孪生**技术加速开发周期，虚拟仿真减少物理样机
- 基于结温估算的温度保护替代传统 NTC 监控
- **AUTOSAR 架构 + OTA 升级**成为标配，控制器"出厂即定型"走向"持续进化"
- 商业模式：硬件订阅/性能即服务渗透率 2025 年达 14%

### 9.3 政策与标准

- "十五五"规划将新能源与高端装备列为战略支柱
- 中国 2025 年发布碳达峰场景下电机系统能效提升行动方案：新增工业电机变频配套比例 ≥65%
- IE4 及以上能效等级产品市占率 2025 年首次突破 50%，IE5/IE6 成为主流方向
- 欧盟生态设计法规将电机控制器纳入一级能效管控（2027 年最低能效指数 0.85）

### 9.4 国产化现状

- **短板**：高端车规级 IGBT/SiC 模块、高算力控制芯片、功能安全软件仍依赖进口
- **突破**：中低压变频、家电级方案国产化率高；高端伺服（亚微米级定位）仍由欧美日主导（占 83% 高精度市场份额）
- 中国专利累计申请占全球 44%，研发投入强度约 6.8%
