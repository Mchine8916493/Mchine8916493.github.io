C 语言是嵌入式、操作系统、驱动开发与高性能计算的基石。本文面向初学者，系统梳理 C 语言**基础**知识点，从"程序长什么样"到"怎么组织代码"，为后续的进阶学习（指针深入、内存管理、编译链接）打下地基。建议配合《C语言进阶知识点详解》一起阅读。

# 一、第一个 C 程序

## 1.1 Hello World 逐行拆解

```c
#include <stdio.h>        // 预处理指令：引入标准输入输出库的头文件

int main(void) {          // 程序入口函数，int 是返回类型
    printf("Hello, World!\n");   // 调用库函数输出，"%n" 是换行
    return 0;             // 返回 0 表示程序正常结束
}
```

- `main` 是**程序入口**，一个程序只能有一个
- `printf` 里的 `\n` 是换行转义字符
- `return 0;` 把退出码交给操作系统（0 = 成功，非 0 = 出错）

## 1.2 编译运行

```bash
gcc hello.c -o hello     # 编译生成可执行文件 hello
./hello                  # 运行
gcc hello.c -o hello && ./hello   # 一步到位
```

## 1.3 程序的基本结构

```
预处理指令（#include / #define）
┌──────────────────────────────┐
│ 全局变量声明                  │
│ 函数声明（原型）              │
│ 函数定义                      │
│   ┌────────────┐              │
│   │ 局部变量    │              │
│   │ 语句序列    │              │
│   │ return     │              │
│   └────────────┘              │
└──────────────────────────────┘
```

# 二、基本数据类型

## 2.1 整数类型

| 类型 | 典型大小 | 取值范围（典型 32 位平台） |
|---|---|---|
| `char` | 1 字节 | -128 ~ 127 |
| `unsigned char` | 1 字节 | 0 ~ 255 |
| `short` | 2 字节 | -32768 ~ 32767 |
| `int` | 4 字节 | -2147483648 ~ 2147483647 |
| `unsigned int` | 4 字节 | 0 ~ 4294967295 |
| `long` | 4 或 8 字节 | 平台相关 |
| `long long` | 8 字节 | -2^63 ~ 2^63-1 |

> **记忆**：`sizeof(int)` 在大多数平台是 4 字节，但 C 标准只保证 `int ≥ 16 位`。想要确定宽度用 `<stdint.h>` 的 `int32_t`、`uint8_t` 等。

## 2.2 浮点类型

```c
float       f = 3.14f;   // 单精度，4 字节，约 6~7 位有效数字
double      d = 3.14159; // 双精度，8 字节，约 15~16 位有效数字
long double l = 3.14L;   // 扩展精度，平台相关
```

> 字面量加 `f`/`L` 后缀指定类型；默认小数是 `double`。浮点不能直接比较相等（精度问题）。

## 2.3 布尔与字符

```c
#include <stdbool.h>
bool flag = true;      // C99 起支持 bool / true / false
char ch = 'A';         // 字符用单引号
char c = 65;           // 字符本质是整数（ASCII），'A' == 65
```

## 2.4 sizeof 运算符

```c
sizeof(int)        // 类型大小，单位是字节
sizeof(x)          // 变量大小
```

# 三、变量与常量

## 3.1 变量声明与初始化

```c
int a;              // 声明：此时 a 的值不确定（垃圾值！）
int b = 10;         // 声明并初始化
int c = 0;          // 强烈建议：使用前一定初始化
int x = 1, y = 2;   // 一行声明多个
```

> 未初始化的局部变量是**不确定值**，直接使用属于未定义行为，是初学者的头号陷阱。

## 3.2 常量

```c
#define MAX 100          // 预处理宏常量（无类型，纯文本替换）
const int LIMIT = 50;    // const 常量（有类型，编译期检查）
const double PI = 3.14159;
```

## 3.3 命名规则

- 只能由字母、数字、下划线组成，且**不能以数字开头**
- 不能与关键字（if、int、return 等）重名
- 大小写敏感：`Sum`、`sum`、`SUM` 是三个不同变量
- 常见风格：`snake_case`（变量/函数）、`SCREAMING_CASE`（宏）

# 四、运算符

## 4.1 算术运算符

```c
+  -  *  /  %
```

- `/`：整数相除**截断小数**（`7 / 2 == 3`），浮点相除才保留小数（`7.0 / 2 == 3.5`）
- `%`：取余，仅用于整数（`7 % 2 == 1`）
- 除零是运行时错误

## 4.2 赋值与复合赋值

```c
x = x + 5;   // 等价于
x += 5;      // 复合赋值：+= -= *= /= %= <<= >>= &= |= ^=
```

## 4.3 自增自减

```c
i++;   // 后缀：先使用 i 的值，再自增
++i;   // 前缀：先自增，再使用新值

int i = 5;
printf("%d", i++);   // 输出 5，之后 i 变 6
printf("%d", ++i);   // 输出 6，之前 i 已变 6
```

> 一条语句里不要多次修改同一个变量（`i = i++ + i` 是未定义行为）。

## 4.4 关系与逻辑运算符

```c
==  !=  >  <  >=  <=     // 关系：结果是 0（假）或 1（真）
&&  ||  !                // 逻辑：与、或、非
```

- **短路求值**：`a && b` 若 a 为假则不计算 b；`a || b` 若 a 为真则不计算 b
- `!0 == 1`，`!5 == 0`（C 中任何非 0 值都是"真"）
- 常见错误：`if (a = 5)` 是赋值不是比较！应为 `if (a == 5)`

## 4.5 位运算符

```c
&  |  ^  ~  <<  >>    // 按位与、或、异或、取反、左移、右移
```

## 4.6 条件运算符（三目）

```c
int max = (a > b) ? a : b;   // a>b 成立取 a，否则取 b
```

## 4.7 运算符优先级速记

```
先乘除后加减 → 移位 → 关系比较 → 位与 → 位异或 → 位或 → 逻辑与 → 逻辑或 → 赋值
```

> 记不住优先级就**用括号**，括号永远是最清晰的。

# 五、流程控制

## 5.1 if / else if / else

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

- `if` 只控制紧随其后的**一条语句**；要控制多句必须加大括号 `{}`
- 判断"是否等于 0"可写 `if (!x)` 或 `if (x == 0)`

## 5.2 switch

```c
switch (grade) {
    case 'A': printf("优秀"); break;
    case 'B':
    case 'C': printf("良好"); break;   // 多个 case 共用一个分支
    default:  printf("未知");
}
```

> 别忘 `break`！否则会**穿透**继续执行下一个 case（fallthrough）。

## 5.3 循环：while / do-while / for

```c
// while：先判断后执行
int i = 0;
while (i < 10) {
    printf("%d ", i);
    i++;
}

// do-while：先执行后判断（至少执行一次）
int n;
do {
    printf("请输入正数：");
    scanf("%d", &n);
} while (n <= 0);

// for：最常用，适合固定次数
for (int j = 0; j < 10; j++) {
    printf("%d ", j);
}
```

## 5.4 break / continue

```c
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;   // 跳过本次循环剩余部分
    if (i == 7) break;      // 立即终止整个循环
    printf("%d ", i);       // 输出 0 1 2 4 5 6
}
```

# 六、数组

## 6.1 一维数组

```c
int arr[5];              // 声明：5 个 int，元素未初始化
int nums[5] = {1, 2, 3, 4, 5};   // 完整初始化
int part[5] = {1, 2};    // 部分初始化：其余自动填 0
int auto_size[] = {1, 2, 3};     // 由初始化列表推导大小（=3）

printf("%d", nums[0]);   // 下标从 0 开始
nums[2] = 100;           // 修改元素
```

> 下标越界不会报编译错，但运行时会访问到未知内存（未定义行为）。

## 6.2 数组的遍历

```c
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += nums[i];
}
```

## 6.3 二维数组

```c
int matrix[3][4];       // 3 行 4 列，内存连续存放
int table[2][2] = {{1, 2}, {3, 4}};

// 双重循环遍历
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        matrix[i][j] = 0;
    }
}
```

## 6.4 字符数组与字符串

```c
char name[6] = "hello";       // 数组长度要 +1 给 '\0'
char msg[] = "hello";         // 自动分配 6 字节（含结尾 '\0'）
char words[100];
gets(words);                  // ⚠️ 危险！无边界检查，勿用
fgets(words, sizeof(words), stdin);  // ✅ 安全：限定最多读入大小-1
```

> C 字符串以 `'\0'`（值为 0）结尾，字符串函数靠它判断结束。

# 七、函数

## 7.1 函数的定义与调用

```c
// 函数定义：返回类型 + 函数名 + 参数列表 + 函数体
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int result = add(3, 5);   // 调用
    printf("%d\n", result);   // 输出 8
    return 0;
}
```

## 7.2 函数原型（声明）

如果函数定义在使用之后，必须先声明（原型）：

```c
int add(int a, int b);   // 函数原型声明

int main(void) {
    int r = add(3, 5);   // 编译器需要先知道 add 存在
    return 0;
}

int add(int a, int b) {  // 定义
    return a + b;
}
```

## 7.3 参数传递：按值传递

```c
void change(int x) {
    x = 100;          // 只是副本
}
int a = 5;
change(a);            // 调用后 a 仍然是 5
```

> C 函数参数**默认按值传递**（拷贝）。要修改调用者的变量，必须传指针（进阶篇详述）。

## 7.4 返回值与提前返回

```c
int divide(int a, int b) {
    if (b == 0) return -1;    // 提前返回，处理错误
    return a / b;
}
```

## 7.5 void 类型

```c
void hello(void);     // 无参数、无返回值的函数
```

# 八、指针入门

## 8.1 指针是什么

指针是**存放地址的变量**。用 `&` 取地址，用 `*` 解引用：

```c
int x = 42;
int *p = &x;     // p 存放 x 的地址

printf("%d", x);      // 42（直接访问）
printf("%d", *p);     // 42（通过指针解引用访问）
*p = 100;             // 通过指针修改 x
printf("%d", x);      // 100
```

## 8.2 图解

```
变量 x（地址 0x1000）┌─────┐
                     │ 42  │
                     └─────┘
指针 p（地址 0x2000）┌──────────┐
                     │ 0x1000   │ ← p 的值是 x 的地址
                     └──────────┘
```

## 8.3 指针的声明

```c
int *p;     // p 是一个指向 int 的指针
char *cp;   // p 是一个指向 char 的指针
```

> `*` 跟随变量名：`int *p1, *p2;` 声明两个指针；`int *p1, p2;` 中 p2 是普通 int！

## 8.4 NULL 与空指针

```c
int *p = NULL;      // NULL 表示"不指向任何有效地址"
if (p != NULL) {    // 使用前检查
    *p = 5;
}
```

# 九、作用域与生命周期

## 9.1 局部变量 vs 全局变量

```c
int global = 10;          // 全局变量：函数外，任何函数可见

void f(void) {
    int local = 5;        // 局部变量：函数内可见
    static int count = 0; // 静态局部：跨函数调用保留，只初始化一次
    count++;
}
```

| | 局部变量 | 全局变量 | 静态局部 |
|---|---|---|---|
| 作用域 | 所在函数/块 | 整个文件 | 所在函数 |
| 生命周期 | 函数调用期间 | 程序全程 | 程序全程 |
| 初始化 | 垃圾值 | 自动清零 | 只初始化一次 |

## 9.2 块作用域

```c
{
    int t = 1;    // t 只在这个花括号内有效
}
// 这里访问 t 会编译错误
```

# 十一、输入输出

## 11.1 格式化输出 printf

```c
printf("%d\n", 10);        // 十进制整数
printf("%f\n", 3.14);      // 浮点（默认 6 位小数）
printf("%.2f\n", 3.14159); // 保留 2 位小数
printf("%c\n", 'A');       // 字符
printf("%s\n", "hello");   // 字符串
printf("%x\n", 255);       // 十六进制
printf("%o\n", 8);         // 八进制
printf("%ld\n", 123456L);  // 长整数
printf("%5d\n", 42);       // 宽度 5 右对齐
printf("%-5d\n", 42);      // 宽度 5 左对齐
printf("%p\n", &x);        // 指针地址
printf("%%");              // 输出百分号本身
```

## 11.2 格式化输入 scanf

```c
int n;
double d;
scanf("%d", &n);       // ⚠️ 必须加 &（取地址）！
scanf("%lf", &d);      // 读 double 用 %lf
```

> 初学者最常见错误：`scanf("%d", n)` 忘了 `&`，会导致程序崩溃或行为未定义。

## 11.3 getchar / putchar

```c
char ch = getchar();     // 读一个字符
putchar(ch);             // 输出一个字符
```

# 十二、综合实例

## 12.1 猜数字游戏

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand(time(NULL));
    int secret = rand() % 100 + 1;   // 1~100 随机数
    int guess = 0, tries = 0;

    printf("猜数字游戏（1~100）\n");
    do {
        printf("请输入你的猜测：");
        scanf("%d", &guess);
        tries++;
        if (guess > secret) {
            printf("太大了！\n");
        } else if (guess < secret) {
            printf("太小了！\n");
        }
    } while (guess != secret);

    printf("恭喜！你用了 %d 次猜中。\n", tries);
    return 0;
}
```

## 12.2 冒泡排序

```c
void bubble_sort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int tmp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = tmp;
            }
        }
    }
}
```

## 12.3 求最大公约数（辗转相除法）

```c
int gcd(int a, int b) {
    while (b != 0) {
        int tmp = a % b;
        a = b;
        b = tmp;
    }
    return a;
}
```

# 十三、常见错误与调试

## 13.1 初学者高频错误

| 错误 | 正确写法 | 原因 |
|---|---|---|
| `if (a = 5)` | `if (a == 5)` | = 是赋值，== 才是比较 |
| `scanf("%d", n)` | `scanf("%d", &n)` | scanf 需要地址 |
| `int a[5]; a[5]=1;` | 下标 0~4 | 越界是未定义行为 |
| 忘记初始化 | `int sum = 0;` | 垃圾值参与运算 |
| `7 / 2 == 3.5` | `7 / 2 == 3` | 整数除法截断 |
| 字符串数组不给 `\0` 留位 | `char s[6]="hello"` | 少 1 个字节越界 |

## 13.2 调试技巧

```c
printf("调试：a=%d b=%d\n", a, b);   // 最简单的打印调试
```

- 编译加 `-Wall -Wextra` 让编译器提示潜在错误
- 使用 GDB 断点单步调试
- 缩小问题范围：二分注释代码

# 十四、编码风格建议

```c
#include <stdio.h>

// 1. 命名清晰：变量用名词，函数用动词
int student_count = 0;
void print_report(void) { /* ... */ }

// 2. 适当缩进与空格，保持可读性
for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}

// 3. 复杂逻辑加注释
if (a > 0 && b > 0) {   // 要求两个数都为正
    // ...
}

// 4. 一行只做一件事，语句间逻辑连贯
```

**核心原则**：代码是写给**人**看的，顺便给机器运行。可读性 > 炫技。

# 总结

C 语言基础知识点构成一张完整的入门地图：

> **程序结构 → 数据类型 → 变量常量 → 运算符 → 流程控制 → 数组 → 函数 → 指针入门 → 作用域 → 预处理 → 输入输出**

掌握这些内容后，你就可以写出完整的小程序（猜数字、排序、简易计算器）。下一站就是进阶篇：指针深入、内存管理、结构体、位操作、编译链接与未定义行为。

> **一句话记住**：C 语言基础 = 用"变量存数据、运算符算数据、流程控流程、函数组逻辑"，把这三件事练到条件反射，就算入门了。
