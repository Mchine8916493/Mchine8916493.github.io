# 使用 Ventoy 制作 U 盘启动盘完全指南

> 需求：一个 U 盘装下所有 ISO，想启动哪个就启动哪个，不用反复格式化。Ventoy 正是为此而生。

本文从零开始，讲清楚 Ventoy 的核心原理、安装步骤、日常用法和常见坑，帮你彻底告别「一个系统一个U盘」的旧时代。

## 一、Ventoy 是什么？

**Ventoy** 是一款开源的 U 盘启动盘制作工具，它最大的特点可以用一句话概括：

> 安装一次 Ventoy 到 U 盘后，你**只需要把 ISO/IMG/WIM/VHD(x)/EFI 文件直接复制进 U 盘**，启动时从菜单中选择即可。

它不要求 U 盘容量够大装下所有镜像（因为不是解压写入），也不要求你对每个镜像单独制作一次启动盘。

### 核心特性

| 特性 | 说明 |
|---|---|
| 免解压免写入 | 直接把镜像文件拷进 U 盘分区，即拷即用 |
| 一 U 盘多系统 | 一个盘同时容纳 Windows / Linux / PE / macOS 等数十个镜像 |
| 无损升级 | 升级 Ventoy 不影响 U 盘里已有的镜像文件 |
| 双启动架构 | 同时支持 Legacy BIOS 和 UEFI（含安全启动） |
| 跨平台 | Windows、Linux、macOS 都有对应版本 |
| 开源免费 | GPLv3 协议，项目托管在 GitHub |
| 兼容性好 | 已兼容 1000+ ISO 镜像，官方有验证清单 |

### 与其他工具对比

| 工具 | 方式 | 一个U盘多系统 | 镜像更新 |
|---|---|---|---|
| **Ventoy** | 引导器直读镜像 | ✅ 多个镜像共存 | ✅ 拷入即用 |
| Rufus | 单镜像写入 | ❌ 一次一个 | ❌ 需重新写入 |
| UltraISO | 单镜像写入 | ❌ 一次一个 | ❌ 需重新写入 |
| dd | 单镜像写入 | ❌ 一次一个 | ❌ 需重新写入 |

## 二、制作前的准备

### 1. 硬件准备

- **U 盘一个**：建议 ≥ 16GB。4GB 的盘也能用，但放不下几个大镜像
- 电脑一台：Windows 10/11 或 Linux 均可

> ⚠️ **制作过程会清空 U 盘全部数据**，操作前务必把 U 盘里的资料备份出来！

### 2. 软件下载

- 从 Ventoy 官网下载最新版：`https://www.ventoy.net/cn/download.html`
- 或从 GitHub Releases 下载：`https://github.com/ventoy/Ventoy/releases`
- 解压即可使用，**无需安装**（Windows 版是绿色软件）

## 三、Windows 下制作步骤

### 第 1 步：解压并运行

1. 解压下载的 `ventoy-x.x.xx-windows.zip`
2. 进入解压目录，双击运行 `Ventoy2Disk.exe`
3. 若弹出 UAC 权限确认，点击「是」

### 第 2 步：选择 U 盘并安装

1. 设备栏选择你的 U 盘（**务必核对盘符，别选成硬盘！**）
2. 分区类型选择：
   - **MBR**：兼容性最好，Legacy BIOS 和 UEFI 都能启动（默认推荐）
   - **GPT**：仅支持 UEFI 启动，适合新款电脑
3. 点击「安装」按钮

```
┌─────────────────────────────────────────────┐
│              Ventoy2Disk  v1.x              │
│  设备: [SanDisk USB 32GB   ▼]               │
│  ┌─────────────────────────────────────┐    │
│  │ Ventoy 将安装到该设备。             │    │
│  │ ⚠ 设备上的所有数据将被清空！       │    │
│  │ 已确认清除所有数据 ☑              │    │
│  └─────────────────────────────────────┘    │
│  分区类型: [MBR ▼]      [安全启动支持☐]      │
│              [ 安装 ]   [ 更新 ]             │
└─────────────────────────────────────────────┘
```

4. 确认提示后等待写入完成（约 1~2 分钟）

### 第 3 步：拷贝镜像

安装完成后，U 盘会变成两个分区：

- **exFAT 分区（大分区）**：Ventoy 的可移动存储区，**把 ISO 文件直接拷进来**
- 小分区（VTOYEFI）：引导分区，不用管它

拷贝完成后，U 盘启动盘就做好了。

## 四、Linux 下制作步骤

Linux 下有图形界面和命令行两种方式。

### 方式一：图形界面（推荐桌面用户）

```bash
# 解压并进入目录
tar xzf ventoy-x.x.xx-linux.tar.gz
cd ventoy-x.x.xx

# 运行图形安装界面
sudo sh Ventoy2Disk.sh
```

### 方式二：命令行

```bash
# 先查看 U 盘设备号（如 /dev/sdb）
lsblk

# 安装 Ventoy 到 /dev/sdb（会清空整个设备！）
sudo sh Ventoy2Disk.sh -i /dev/sdb

# 若需要 GPT 分区 + 安全启动支持
sudo sh Ventoy2Disk.sh -i -g /dev/sdb
```

| 参数 | 含义 |
|---|---|
| `-i` | 安装 Ventoy（install） |
| `-u` | 升级 Ventoy（update） |
| `-g` | 使用 GPT 分区 |
| `-s` | 启用安全启动支持 |

安装完成后，把 ISO 拷贝到 exFAT 分区即可。

## 五、使用：从 U 盘启动

### 第 1 步：重启并进入启动菜单

- 重启电脑，开机时按启动热键：
  - **联想/ThinkPad**：F12
  - **戴尔**：F12
  - **惠普**：F9
  - **华硕**：F8 或 Esc
  - **宏碁**：F12
  - **微星**：F11
  - **苹果 Mac**：开机按住 Option
- 在弹出的启动菜单中选中 U 盘（通常显示品牌名，如 SanDisk/Kingston）

### 第 2 步：Ventoy 菜单选镜像

进入 Ventoy 图形菜单后，用键盘上下键选择你要启动的 ISO，回车即可。

```
┌────────────── Ventoy 1.0.98 ──────────────┐
│  ├─ ArchLinux-2026.08-x86_64.iso         │
│  ├─ ubuntu-24.04-desktop-amd64.iso       │
│  ├─ Win11_24H2_Chinese_Simplified.iso    │
│  ├─ WePE_64_V2.3.iso                     │
│  └─ kali-linux-2026.1-live-amd64.iso     │
└───────────────────────────────────────────┘
```

> 新版 Ventoy 还支持 **VTOY_DEFAULT_MENU_MODE 配置** 让菜单以列表/图形模式显示，支持主题美化。

### 第 3 步：按正常流程安装系统

选完镜像后就是各家安装器正常的安装流程了（Windows 安装、Ubuntu 安装、PE 桌面等），不再赘述。

## 六、常见问题排查

### Q1：插上 U 盘不识别 / 无法引导

- **确认启动顺序**：BIOS 里把 U 盘（USB）排在硬盘之前，或用启动热键
- **开启 CSM**：老电脑 Legacy 模式下需要 BIOS 中开启 CSM/兼容模式
- **换 USB 口**：优先插机箱后置 USB 2.0 口（部分镜像对 USB3.0 主控兼容差）
- **换 U 盘**：个别杂牌 U 盘主控不兼容，换知名品牌盘更稳

### Q2：UEFI 模式启动报「安全启动」问题

- 方法一：BIOS 中临时关闭 Secure Boot（最省事）
- 方法二：安装 Ventoy 时勾选「安全启动支持」，并在首次启动时**按提示在 BIOS 里注册 MOK 证书**（Enroll key）

### Q3：部分 ISO 启动后黑屏 / 卡住

- Ventoy 菜单中按 **`F1` 切换启动模式**（MBR → GPT → WIMBOOT 等）
- 某些 Linux 发行版需要按 `E` 编辑启动参数加 `nomodeset`
- 检查 ISO 是否损坏（对比官方 SHA256 校验值）

### Q4：U 盘容量变小了？

这是正常的——Ventoy 会占用约 32MB 建引导分区，剩余容量都在大分区里。

### Q5：提示「磁盘写保护」

- 检查 U 盘侧面的物理写保护开关
- 用 `sudo sh Ventoy2Disk.sh -u /dev/sdb` 升级/重装试试

## 七、进阶玩法

### 1. 无损升级 Ventoy

```bash
# 保留 U 盘内所有镜像，仅升级引导器
sudo sh Ventoy2Disk.sh -u /dev/sdb
```

### 2. 持久化数据（Persistent）

Ventoy 支持为 Debian/Ubuntu 系 ISO 创建持久化存储，让 Live 系统的文件和安装的软件在重启后保留：

1. 用 `VentoyPlugson` 或插件目录配置
2. 在 `ventoy/ventoy.json` 中为指定 ISO 关联持久化文件

### 3. 集成 PE 系统

把 PE 的 WIM 镜像和配套文件放进 `ventoy/` 目录的 wimboot 结构，或直接用 PE ISO，即可在 Ventoy 菜单里启动 Windows PE 做维护。

### 4. 本地启动菜单美化

Ventoy 支持主题：下载主题包后放到 U 盘 `ventoy/themes` 目录，重启即生效。

### 5. 校验镜像完整性

把镜像的 SHA256 值写入同目录的 `.sha256` 文件，Ventoy 启动时会自动校验并提示。

## 八、总结

Ventoy 的核心价值在于**把「制作启动盘」从一次性操作变成了日常拷贝操作**：

- 一个 U 盘 = 一个移动系统仓库
- 更新镜像 = 拷入新文件（无需重新写盘）
- 升级工具 = 无损更新引导器

无论你是装机老手还是刚入门的新手，Ventoy 都是目前制作多系统启动盘的最优解。官网文档也很详尽，遇到问题可以参考：`https://www.ventoy.net/cn/doc_start.html`

> 💡 小贴士：建议 U 盘里同时保留一个 PE（如微PE/优启通）镜像作为「急救盘」，系统出问题时随时能进 PE 修复。
